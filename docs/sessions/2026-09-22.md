# Sessão 2026-09-22 — Correção do acesso local à MB News

## Resumo

O acesso local à edição de setembro retornava 404 porque o servidor estático estava servindo a raiz do repositório, enquanto a edição fica em `public/pages/`.

## Solução

Foi iniciado um servidor local com mapeamento compatível com a publicação: `index.html` é servido da raiz e os caminhos `/pages`, `/assets`, `/images` e `/videos` são resolvidos dentro de `public/`.

## Validação

- `http://localhost:8080/index.html` — HTTP 200
- `http://localhost:8080/pages/mb-news-setembro-2026.html` — HTTP 200
- CSS e imagem da edição de setembro — HTTP 200

## Próximo passo

A tela de carregamento existia somente em abril. O CSS, o elemento `#loader` e o atraso de 1,6 segundo no JavaScript foram removidos. A página agora abre diretamente, como as demais edições.
