## Problemas e soluções

- Windows bloqueou subprocessos das ferramentas: executados novamente com aprovação de execução fora do sandbox.
- Credencial temporária de sincronização expirou: renovada para o mesmo Site, sem criar outro projeto nem alterar seu prazo.
- R2 devolve metadados de range mesmo para objeto completo no ambiente local: corrigido para responder 206 somente quando a requisição pede Range.
- Upload R2 exige stream com tamanho conhecido: usado FixedLengthStream, validando assinatura e limites sem manter o vídeo inteiro na memória.
- Navegador de QA indisponível: não foi feita inspeção visual nem teste de reprodução de codecs; realizado teste HTTP das APIs.
