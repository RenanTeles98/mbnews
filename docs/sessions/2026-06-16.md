## Resumo

- Corrigido o erro 404 da URL `/pages/mb-news-abril-2026.html` em producao.
- Publicado novo deploy na Vercel e validada a resposta `200 OK` para Abril, home e imagens publicas.

## Problemas Encontrados

- A Vercel esta configurada como deploy estatico pela raiz (`outputDirectory: "."`).
- Com essa configuracao, arquivos em `public/pages/` ficavam acessiveis em `/public/pages/`, mas a navegacao da MB News apontava para `/pages/`.

## Solucoes

- Adicionados rewrites em `vercel.json`:
  - `/pages/:path*` para `/public/pages/:path*`
  - `/images/:path*` para `/public/images/:path*`
- Enviado commit para o GitHub e executado deploy de producao na Vercel.

## Decisoes

- Manter os HTMLs arquivados em `public/pages/`, seguindo a regra do projeto.
- Manter as URLs publicas limpas no padrao `/pages/...`.
