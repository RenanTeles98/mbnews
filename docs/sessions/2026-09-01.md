# Sessao 2026-09-01 - Liberacao para iframe

## Resumo

- Configurado o deploy da Vercel para permitir que o projeto seja aberto dentro de iframes externos.

## Alteracao

- Removido `X-Frame-Options: SAMEORIGIN`.
- Adicionado `frame-ancestors *` a Content Security Policy.
- Preservado `frame-src 'none'`, pois ele controla somente iframes carregados pelo projeto.
